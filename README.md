# BTCS203P DBMS Lab Solutions

Beginner-friendly SQL solutions for the five DBMS lab sheets, written for MySQL Workbench.

## Files

- `Lab-Sheet-1-DDL.sql` — CREATE, ALTER, DROP and constraints
- `Lab-Sheet-2-DML.sql` — INSERT, UPDATE and DELETE
- `Lab-Sheet-3-SQL-Functions.sql` — number, aggregate, character, conversion and date functions
- `Lab-Sheet-4-SQL-Operators.sql` — arithmetic, logical, comparison, special and set-operation examples
- `Lab-Sheet-5-SQL-Joins.sql` — INNER, LEFT, RIGHT, CROSS, NATURAL and SELF JOIN examples

## How to run

1. Open MySQL Workbench and connect to your MySQL server.
2. Open one `.sql` file.
3. Run the statements in order using the lightning button.
4. Check the Result Grid after each `SELECT`.

Each file creates or resets the tables it needs. Run one lab sheet at a time. The scripts use sample data and may replace tables with the same names in the `CollegeDB` database.
